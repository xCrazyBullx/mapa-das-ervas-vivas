# Mapa das Ervas Vivas

Plataforma colaborativa para registrar, localizar e confirmar a presença de plantas.

## Tecnologias previstas

- React + Vite
- Supabase (autenticação, banco de dados e fotos)
- Leaflet + OpenStreetMap
- Cloudflare Pages para hospedagem

## Funcionalidades planejadas

- Mapa de plantas aprovadas
- Cadastro de plantas com fotos e localização
- Aprovação por moderadores antes da publicação
- Confirmação presencial periódica
- Histórico de alterações e auditoria

> Este repositório está em fase inicial de desenvolvimento.
